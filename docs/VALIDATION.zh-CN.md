## 已完成的验证

- 157 节点三轮冷页缓存配对对照全部完成：6 次全新传输全部校验，942 次清缓存屏障成功；157 个不同 boot ID，471 个任务进程记录全部确认已停止。详见 [正式结果](COLD-RESULTS.zh-CN.md)。
- Go 单元测试启用 race detector，通过；go vet 通过。
- 真正的三进程链 A→B→C 测试通过：中断 B、修改其部分文件、重新启动，最终三个文件 SHA-256 一致，且 B 确实向 C 上传。
- 三进程测试也使用 race 版可执行文件执行，未发现 DATA RACE。
- CLI 测试通过：无参数入口、各子命令 --help、help COMMAND、缺少必要参数、空任务目录、jobs 等入口。
- 校验缓存测试通过：清单不一致、inode 被替换、内容修改后恢复 mtime 均会使缓存失效。
- 并行任务测试通过：并发不超出指定上限；发生错误能返回失败并取消未启动工作。
- 真实 5 节点、40,188,444,672 字节介质分发及整文件 SHA-256 验证通过。
- 对真实文件执行整批 resume，通过验证且重新下载字节数为 0；该项与全新文件测速分开。
- 真实 45 节点、1 种子＋44 接收节点分发通过，全部完整接收并校验；随后逐台查询本任务 PID，45 个 peer 均已停止。
- 两节点小文件冷页缓存驱动预检通过，覆盖新目录门禁、sync/drop_caches、rsync 完整 literal 字节、即时 SHA-256 和 SCDP 完整下载量检查。

开发期间有一次额外验证命令被取消，未将该次计为通过；之后单独补做 race 三进程检查，已通过。未使用被取消或未完整取得输出的检查作为成功证据。

## 平台与构建

实际工具链为 Go 1.27.4；项目声明 Go 1.24+。发布文件分别为 Linux x86_64（GOARCH=amd64）和 Linux aarch64（GOARCH=arm64），CGO_ENABLED=0，trimpath、buildvcs=false，附 SHA256SUMS。file 检查为静态 ELF。

发布前在独立输出路径重新构建两架构，SHA-256 与正式测速冻结文件完全一致。

实际集群验证使用 x86_64。ARM64 只有交叉构建检查，本次没有 ARM 硬件执行证据。不得把“已交叉编译”写成“已在 GB 系列实测”。

密码登录逻辑提供内存 askpass，实际集群使用已有 SSH 公钥；本次没有以真实密码账户做端到端登录验证。
